# Навигатор за Android (ARCore)

Тенка нативна обвивка околу истото јадро од `src/` (JavaScript):

```
ARCore (Kotlin)  ──кадар 10×/s──▶  WebView (јадро + UI)  ──▶  глас, вибрација (Kotlin)
 поза + feature-точки              мапа, рута, упатства         TTS, Vibrator
```

| Датотека | Задача |
|---|---|
| `ArFrames.kt` | ARCore сесија, подот (најниска хоризонтална рамнина), поза и точки → JSON |
| `JsBridge.kt` | објектот `Android` за JS: `say`, `vibrate`, `listen`, `secureSave/Load` |
| `Speech.kt` | TTS (македонски, со резервен глас) и препознавање говор (на уред кога е можно) |
| `SecureStore.kt` | мапата шифрирана со клуч од Android Keystore, без лозинка |
| `MainActivity.kt` | дозволи, ARCore инсталација, животен циклус; копче за јачина надолу = слушај |

Нема `INTERNET` дозвола во манифестот. Мапата и гласот не можат да ја напуштат апликацијата.

## Градење

APK-то се гради во GitHub Actions (`.github/workflows/android.yml`) и излегува како артефакт `navigator-debug-apk`.
Локално: `npm run build`, па `gradle -p android assembleDebug` (JDK 17, Android SDK 34).
Gradle го копира `dist/index.html` во assets.

## Како работи во просторија

1. Првиот пат застани на „почетна точка“ (на пр. до врата, со грб кон ѕид) и кажи „запомни тука старт“.
2. Одај низ просторијата и кажи „запомни тука кујна“, „запомни тука кревет“ на местата што сакаш.
3. Кажи „оди до кујна“. ARCore ја дава позицијата, а feature-точките над подот (8 до 190 cm) стануваат пречки.
4. Ако ARCore ја изгуби позицијата, апликацијата застанува, вибрира долго и бара потврда.

## Што не е докажано (прочитај пред да се потпреш)

Овој код е напишан без да може да се преведе или да се пушти на уред. Јадрото во JavaScript е тестирано
(`npm test`, вклучително синтетички ARCore кадри), но Kotlin делот не е. Прво на уред:

- Дали `ArFrames` испраќа кадри и дали `tracking` преминува во `PAUSED` кога се покрива камерата.
- Подот: ARCore му треба време да најде рамнина. Додека нема под, пречките не се мапираат.
- **Порамнување меѓу сесии.** ARCore нема офлајн постојана мапа. Секоја сесија почнува во нов координатен систем,
  па зачуваната мапа важи само ако корисникот почне од истата точка и во истата насока. Грешка од неколку
  степени станува метри на 5 m. Следен чекор: маркер (QR или AprilTag) на почетната точка за автоматско порамнување.
- Feature-точките не гледаат прагови под ~8 cm, ѕидови без текстура и стакло. За тоа е потребен Depth API (ToF).
- Македонски TTS и офлајн препознавање говор ги нема на секој телефон. Апликацијата кажува кога користи резерва.
- Дали пречка што исчезнала (поместен стол) се брише: сега не се брише.
