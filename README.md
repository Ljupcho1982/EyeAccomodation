# Навигатор

Внатрешна навигација за слепи, слабовидни лица и корисници на колички. Упатствата се во метри и по часовник
(„сврти кон 3 часот, па оди 2 метри“), а не во чекори. Меѓу свртувањата телефонот вибрира:
**две лесни = патеката е лево, една силна = десно.**

Две верзии на истото јадро: **симулатор** во прелистувач и **Android апликација со ARCore** (`android/`, видете `android/README.md`). Следни чекори: тест на уред, порамнување меѓу сесии, ARKit.

## Стартување

```
npm test         # 20 тестови на јадрото
npm run build    # создава dist/index.html (еден фајл)
```

Отвори го `dist/index.html` директно во прелистувач. Нема сервер и работи без интернет
(само фонтовите се вчитуваат од Google Fonts кога има мрежа; без нив се користи системскиот фонт).
`dist/artifact.html` е истата страница како фрагмент за објава како Artifact.

## Што има

| Модул | Задача |
|---|---|
| `src/grid.js` | мрежа од 5 cm; секоја ќелија ја чува висината на предметот |
| `src/profile.js` | профил → поставки (ширина, маргина, дозволена висина на праг, излезни канали) |
| `src/planner.js` | A* со одржување на растојание според профилот; „тесниот премин“ и високите прагови се исклучени |
| `src/guidance.js` | метри + часовник, вибрациски шеми |
| `src/session.js` | состојби, нов предмет → предупредување + нова рута, **загубена локализација → стоп** |
| `src/voice.js` | граматика за команди на македонски и англиски (текст → намера) |
| `src/store.js` | AES-GCM + PBKDF2; мапата останува на уредот |
| `src/mapping.js` | ARCore поза и точки → мапа; порамнување со почетна точка |

## Профил (без диоптрија)

Диоптријата ја мери рефракциската грешка што ја корегираат очилата, не како човек се движи. Затоа профилот користи:
острина по корекција, видно поле, светлосна перцепција и, за количка, вистинска ширина и најголем праг.
Границите (0,05 = слеп според СЗО, 0,3 = слабовиден) се почетни вредности што треба да ги потврдат О&М инструктори.

Безбедносни правила:
- ако избраната основа е построга од внесените бројки, важи построгото;
- профил што го внел самиот корисник е означен како непотврден;
- „слеп“ профил нема екран: само глас и вибрации.

## Ограничувања (искрено)

- Локализацијата е симулирана. Реалната доверба во позицијата доаѓа од ARCore/ARKit.
- Препознавањето говор во прелистувач често оди преку мрежа; `processLocally` се бара кога е поддржан.
  Вистинската апликација мора да вклучи офлајн модел (на пр. Vosk или Whisper).
- Праговите и маргините не се клинички валидирани. Не е замена за бастон или куче водич.
